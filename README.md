# Ubuntu Metro Tiles

面向 **Ubuntu 24.04 LTS（GNOME 46 / GTK4 / Wayland）** 开发的 Windows Phone 风格半透明桌面磁贴墙与方正桌面美化项目。

## 设计原则

- **方正克制**：严格 `0px` 直角边界与等宽等高网格，贴合方形屏幕与常见第三方应用（IDE、浏览器、终端）的直角几何。
- **透出壁纸**：磁贴间隙全透明、磁贴内部支持 `0% ~ 75%` 不透明度实时调节，可选「统一透玻璃」或「彩色半透明」两种视觉流派。
- **以无悬浮纯平面为基准**：默认采用无阴影、无位移的纯平面细线框；立体悬浮效果（落影、玻璃高光边与悬停上浮）作为独立开关按需开启。
- **锁定 Ubuntu 24.04**：专注 GNOME 46 + GTK 4.14，保持实现轻量可控。

## 当前进度（v0.1 原型）

当前已提供零系统改动的 GTK4 原生交互原型（`src/metro_tiles.py`），支持：

- 自动探测本机已安装应用并生成默认磁贴，点击直接启动
- 实时动态磁贴：走秒时钟与本机 CPU / 内存监控
- 右键或点击「编辑」实时切换单块磁贴尺寸（`1×1` / `2×1` / `2×2` / `4×2`）、配色与排列顺序
- 实时调节不透明度、`悬浮：关/开` 开关与 `透玻璃 / 彩色透` 风格切换
- 状态持久化保存于 `~/.config/ubuntu-metro-tiles/state.json`

## 快速运行

依赖 Ubuntu 24.04 系统自带的 `python3`、`python3-gi`、`gir1.2-gtk-4.0`：

```bash
python3 src/metro_tiles.py
```

## 后续规划

1. **桌面底层固定扩展（GNOME Shell 46）**：参考 Desktop Icons NG 的桌面窗口管理机制，将磁贴墙固定在壁纸之上、所有应用窗口之下，脱离窗口列表与 Alt+Tab。
2. **完整磁贴管理**：支持从系统 `.desktop` 清单增删应用磁贴、分组标题、自定义快捷命令与拖拽排布。
3. **更多动态磁贴与配套方正样式**：天气/便签/磁盘等轻量动态磁贴，以及可选的 Ubuntu 24.04 直角顶栏/Dock 配套样式。
